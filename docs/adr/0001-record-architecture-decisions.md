# ADR 0001: Record Architecture Decisions

## Status
Accepted

## Context
We need to record architectural decisions so future contributors (human or AI)
understand why things are the way they are.

## Decision
We use Architecture Decision Records (ADRs) in `docs/adr/`.

## Consequences
- Each significant design choice gets a numbered markdown file.
- ADRs are immutable once accepted; superseded ones link to their replacement.
