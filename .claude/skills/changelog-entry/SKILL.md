# Changelog Entry

Add a concise entry to `CHANGELOG.md` for the change just made.

## Steps

1. Read `CHANGELOG.md` and find the latest version heading.
2. Under it, add a bullet in imperative mood (e.g. "add tag filtering to list").
3. Group under `Added` / `Changed` / `Fixed` if those subsections exist.
4. Keep it one line. Do not invent a version bump unless asked.

## Conventions

- Match existing punctuation and tense.
- Reference the user-visible behavior, not the implementation.
